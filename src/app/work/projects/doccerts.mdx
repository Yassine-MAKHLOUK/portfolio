## Overview

DocCerts is a document management platform leveraging blockchain technology for secure, tamper-proof document verification. I was responsible for designing and implementing the complete notification system that keeps users informed about critical events.

## Key Responsibilities

- **Notification architecture design** – Built a scalable, event-driven notification service using Spring Boot, capable of handling high-volume asynchronous messaging.
- **Multi-channel delivery** – Implemented real-time in-app notifications (Angular) plus email alerts, ensuring users never miss document status changes, verification completions, or blockchain certification events.
- **MongoDB schema design** – Created efficient data models for storing notification preferences, delivery logs, and read/unread status for each user.
- **Angular frontend integration** – Developed a dynamic notification center UI with real-time updates, unread badges, and user preference controls using angular materials and websocket.
- **Jira workflow management** – Managed development tasks, bug tracking, and sprints using Jira, ensuring timely delivery aligned with product roadmaps.

## Technologies Used

- **Angular**
- **Springboot**
- **MongoDB**
- **Jira**

## Outcome

Delivered a robust, low-latency notification system that improved user engagement and reduced missed document actions — enabling DocCerts users to stay informed about their critical document workflows without constantly checking the platform.
